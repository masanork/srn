SORANE (空音): The Trust Infrastructure for
Signed Resource Network & Verifiable Data.

The Vision

Breaking the "Integration Trap" through Loosely Coupled Trust. We aim for an AI-agent-ready future where verifiable files decouple the human interface from the backend system.

Read the Vision Statement

「疎結合な信頼」によって、システムの「接続の罠」を突破する。検証可能なファイルによってフロントエンドをバックエンドから解放し、AIエージェントが自由に活躍できる未来を目指します。

ビジョン・ステートメントを読む
CORE VALUE PROPOSITION コア・バリュー
  • Verifiable Ownership Cryptographic signatures prove origin and integrity. No central server required. 暗号署名により、発行元と完全性を証明。中央集権サーバーに依存しません。
  • Portable Trust (LTV) Self-contained verification. Documents verify themselves offline, 50 years later, even if the issuer is gone. 自己完結型の検証。発行元が消滅して50年後でも、オフラインで文書単体で真正性を検証可能。
  • Privacy by Design (L2E) Layer 2 Encryption (HPKE) ensures only the recipient can view the payload. HPKEによるL2暗号化。意図した受信者だけが内容を復号・閲覧可能です。
  • Rebuild-Safe Timestamp Layered Signatures ensure that design updates (HTML rebuilds) do not invalidate the original "Signed At" timestamp. 階層化署名により、デザイン更新（HTMLリビルド）を行っても、オリジナルの「署名日時」が失われることはありません。
