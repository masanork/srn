# 郵便番号自動入力のサンプル

このフォームは、郵便番号を入力すると住所を自動補完するデモです。
単独HTML内にGzip圧縮された郵便番号データ（約12万件）を内蔵しており、オフラインでも高速に動作します。

## 連絡先情報

| 項目 | 入力フィールド |
| --- | --- |
| 郵便番号 | [search:zip (placeholder="例: 100-0001")] |
| 都道府県 | [text:pref (placeholder="自動入力")] |
| 市区町村 | [text:city (placeholder="自動入力")] |
| 町名     | [text:town (placeholder="自動入力")] |
| 番地     | [text:address_detail] |

## 住所一体型フィールド（自動判別テスト）

| 項目 | 入力フィールド |
| --- | --- |
| 郵便番号 | [search:zip2] |
| 住所(一体) | [text:address] |
| 建物名 | [text:building] |

---

### 書き方のポイント

Web/A Form で郵便番号補完を有効にするには、以下のように記述します：

1.  **郵便番号フィールド**:
    - `search` タイプを指定し、キー名に `zip` / `postal` / `郵便` のいずれかを含めます。
    - 例: `[search:zip (placeholder="000-0000")]`
2.  **自動入力先のフィールド**:
    - 都道府県: キー名に `pref` または `都道府県` を含める。
    - 市区町村: キー名に `city` または `市区町村` を含める。
    - 住所・町名: キー名に `town` / `address` / `町` / `住所` のいずれかを含める。
    - 例: `[text:pref]`

これらのフィールドが同じフォーム内（または同じテーブル内）にある場合、郵便番号の入力に合わせて自動的に住所がセットされます。
3桁以上の入力で、ブラウザ標準のドロップダウンによるオートコンプリートも機能します。
