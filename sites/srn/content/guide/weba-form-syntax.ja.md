# Web/A フォーム記法ガイド

Web/A Form は、人間可読性と機械検証性を両立させるため、標準的な Markdown を拡張した独自の記法を採用している。本ガイドでは、サポートされているすべてのタグとフォーマットについて解説する。

## 1. 基本装飾
ラベルや説明文には、標準的な Markdown のインラインスタイルが使用可能である。

| スタイル | 記法 | 結果 |
| :--- | :--- | :--- |
| **太字** | `**テキスト**` または `__テキスト__` | **太字** |
| *斜体* | `*テキスト*` または `_テキスト__` | *斜体* |
| `コード` | `` `コード` `` | `コード` |
| リンク | `[ラベル](URL)` | [ラベル](#) |

## 2. フォームタグ
インタラクティブな入力フィールドを定義する。基本構文は `[タイプ:ID (属性)] ラベル` である。

### 2.1. 基本入力タイプ
| タイプ | 記述例 | 説明 |
| :--- | :--- | :--- |
| `text` | `[text:name] 氏名` | 標準的な一行テキスト入力。 |
| `number` | `[number:age] 年齢` | 数値入力（デフォルトで右寄せ）。 |
| `date` | `[date:birthday] 生年月日` | ブラウザ標準の日付選択。 |
| `textarea` | `[textarea:memo] 備考` | 複数行のテキスト入力。 |

### 2.2. 高度なタイプ
| タイプ | 記述例 | 説明 |
| :--- | :--- | :--- |
| `search` | `[search:v src:vendors] 業者名` | マスターデータを用いた補完入力。 |
| `calc` | `[calc:total formula="SUM(amount)"]` | Excelライクな自動計算フィールド。 |
| `checkbox` | `[checkbox:agree] 同意する` | 真偽値の選択。 |
| `radio` | `- [radio:rank] ランク` | 選択肢。リスト形式で記述（後述）。 |

## 3. リストと選択肢

### 3.1. ラジオボタン
`radio` タグの下にインデントされたリストとして選択肢を記述する。
```markdown
- [radio:satisfaction] 満足度は？
  - 非常に満足
  - [x] 満足（デフォルト）
  - 不満
```

## 4. テーブル

### 4.1. 静的テーブル
標準的な Markdown テーブル。そのままグリッドとして表示される。
```markdown
| 月 | 目標 |
|---|---|
| 1月 | 100 |
```

### 4.2. 動的テーブル（行の追加・削除）
ユーザーが行を自由に追加・削除できるテーブル。
```markdown
[dynamic-table:items]
| No | 品名 | 単価 |
|---|---|---|
| [autonum:no] | [text:item] | [number:price] |
```

### 4.3. マスターデータテーブル
文書の末尾などで定義し、`search` フィールドのデータソースとして利用する。
```markdown
[master:vendors]
| ID | 名称 |
|---|---|
| V01 | 株式会社アップル |
| V02 | 合同会社グーグル |
```

## 5. 属性（モディファイア）
IDの後の括弧 `(...)` 内に記述するオプション。

| 属性 | 例 | 効果 |
| :--- | :--- | :--- |
| `placeholder` | `(placeholder="2025/01/01")` | 未入力時に表示されるヒント。 |
| `align` | `(align:R)` | 文字揃え (L, C, R)。 |
| `copy` | `(copy:src_id)` | 他のフィールドの値を自動コピー。 |
| `suggest` | `(suggest:column)` | 同じ列の既入力を補完候補に出す。 |
| `formula` | `(formula="a + b")` | `calc` フィールドの計算式を定義。 |

## 6. ページ構造
標準の見出しヘッダーを使用して、フォームをタブやセクションに分割する。

*   `# H1`: フォーム全体のタイトル
*   `## H2`: タブ名（複数のH2がある場合、自動的にタブナビゲーションが生成される）
*   `### H3` 以下: ページ内のセクション見出し
