# デジタル主権の再定義：アプリケーション中心主義からの解放
## Web/A による「ゲームチェンジ」の提案

### 1. 序論：「劣化版コピー」の罠からの脱却

欧州を中心に推進されている多くの「デジタル主権」プロジェクト（例：OpenDesk）は、Microsoft 365 や Google Workspace といった米国製巨大プラットフォームの機能を、OSS（Nextcloud, Open-Xchange, etc.）の組み合わせで置き換えようとしている。このアプローチは政治的には正しいが、ユーザー体験の実務においては常に「巨人たちの劣化版コピー」を作る戦いを強いられる。

資本力で劣る勢力が、巨人と同じ土俵（機能競争）で戦って勝てる見込みは薄い。我々が目指すべきは、SaaS の代替品を作ることではなく、**「データの在り方」そのものを変えることで、SaaS の支配力を無力化するゲームチェンジ** である。

### 2. アプリケーション中心主義 vs データ中心主義

現在のデジタル環境は「アプリケーション中心主義」に支配されている。データは特定のアプリ（クラウド）の中に人質として囲い込まれ、ユーザーはそのアプリの UI を通じてしか自分のデータに触れることができない。これがベンダーロックインの本質である。

Web/A は、この構造を**「データ中心主義 (Data-Centric)」**へと反転させる。

*   **Before**: データはアプリに従属する。アプリがなくなればデータも消える（あるいは使えなくなる）。
*   **After**: アプリ（または AI エージェント）がデータに従属する。データはユーザーの手元にあり、そのデータを取り扱うためにエージェントが呼び出される。

### 3. Web標準こそが「主権」の基盤である

「国産OS」や「国産ブラウザ」を作る必要はない。真の主権は、ソフトウェアの国籍ではなく、**「50年後もそのデータを自分の意志でレンダリングできるか」** という能力に宿る。

Web/A が採用する **HTML/CSS** は、特定の企業が独占できない人類共有の資産（Web標準）である。プロプライエタリなデータ形式（.docx や .pdf 等）から、最も普遍的な HTML へとデータを移行することは、特定のベンダーに対する永続的な依存関係を断ち切る最も強力な手段となる。

### 4. AI時代の主権：Bring AI to Data

AI の時代において、デジタル主権の侵害リスクは「データの盗聴」から「知性の独占」へとシフトする。データをクラウド上の巨大 AI にアップロードして解析させるモデルでは、プライバシーとコンテキストの主導権は常にプラットフォーマーにある。

Web/A は **"Local First, AI Ready"** を掲げる。
*   データは自己完結したファイル（Web/A）として手元にある。
*   ユーザーはそのデータに対して、信頼できるローカル LLM や、特定のタスクに特化した AI エージェント・スクリプトを「招待（Invite）」して処理させる。

これは、データが AI の餌になるのではなく、**AI がデータの道具になる** という、主従関係の正常化である。

### 5. 結論：ゲームのルールを変える

我々は、「より良いオフィススイート」を作る競争からは降りる。その代わり、**「オフィススイートがなくても仕事が回る世界」** を構築する。
API エコノミーの複雑さと脆弱さを、ドキュメント・エコノミーの堅牢さと単純さで置き換える。それが Web/A の目指すデジタル主権の形である。
