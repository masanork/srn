SORANE (空音): The Reference Implementation for
Precision Typography & Long-term Authenticiy.

The Vision

Breaking the "Integration Trap" through Loosely Coupled Trust. We aim for an AI-agent-ready future where verifiable files decouple the human interface from the backend system.

Read the Vision Statement

「疎結合な信頼」によって、システムの「接続の罠」を突破する。検証可能なファイルによってフロントエンドをバックエンドから解放し、AIエージェントが自由に活躍できる未来を目指します。

ビジョン・ステートメントを読む
CORE PHILOSOPHY 基本理念
  • Zero Layout Shift (CLS 0) Subsetting fonts per page ensures content renders immediately with correct glyphs. No FOUT/FOIT. フォントをページ毎にサブセット化し、常に正しい字体で即座にレンダリング。レイアウト崩れを防ぎます。
  • Zero Request Overhead Fonts are embedded as Base64 Data URIs. No external font requests. Offline ready. フォントをBase64で埋め込み。外部リクエスト不要で、オフラインでも完全な表示を維持。
  • AI-First Workflows Documents are structured for agents to read, fill, and summarize end-to-end. AIエージェントによる読み取り、自動入力、要約を前提とした構造化ドキュメント。
  • Future-Proof Auth Built-in Post-Quantum Cryptography (ML-DSA-44) support for document signing. 耐量子暗号 (ML-DSA-44) を標準サポート。長期的な真正性を保証。
