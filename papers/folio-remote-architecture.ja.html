ホワイトペーパー：Folio Remote アーキテクチャ ― 信頼の交換機

2024-12-31 By Sorane Project 🤖 AI Generated

1. はじめに：内線交換機（PBX）兼「知的郵便拠点（Postal Hub）」としての Folio Remote

Web/A Folio プロトコルにおいて、Folio Remote の役割は、当初想定されていた「書類鞄（Folio）のローカルとリモートの同期」から、より能動的な「アイデンティティとコンテキストの仲介者」へと進化している。

もはやそれは単なるバックアップや受動的な「私書箱」ではない。個人のアイデンティティと外部ネットワークを繋ぐ**「知的内線交換機（PBX）」であり、かつ、主人の不在時にもメッセージを仕分け、検証し、ルールに基づいて代理応答を行う「知的郵便拠点（Postal Hub） / デジタル郵便局」**である。

このモデルでは、マスターデータは常に個人の手元（Local）にのみ存在し、Remote は「コンテキストに基づく配送と知的窓口業務」に特化した責任を負う。

2. ロール（役割）の再定義と Visitor の導入

Folio 内のアクセス制御は、以下の役割に基づいて厳格に行われる。

  • Admin（管理者）: Folio の全権限を持つ。ルート鍵の所有者。
  • Member（メンバー）: 家族や組織メンバーなど、信頼された内部者。特定のフォルダへの読み書きが可能。
  • Guest（ゲスト）: 一時的なアクセス権を与えられた外部者。did:key 等を用いて特定の手続き（フォームへの回答等）を行う。
  • Visitor（ビジター）: 【新規】他の Folio から発行された正式な DID を保持する外部者。自律的なアイデンティティを持ち、フェデレーション（組織間連携）を通じて認証される。

3. DID マッピングと Inter-Folio ネットワーク

Folio 間の通信（Inter-Folio Networking）を成立させるため、複数の DID モデルを使い分ける。

3.1. did:key から did:web へのバインド

  • Folio内通信: 軽量で使い捨て可能な did:key を主に使用する。
  • 組織間通信: 永続的なエンドポイントを示す did:web を使用する。

Folio Remote は、これらの DID 間の紐付けを Verifiable Credentials (VC) を用いて管理する。この紐付けは必ずしも 1:1 である必要はなく、用途に応じて複数の did:key を一つの did:web（あるいはその逆）にマッピングする動的なアドレッシングを実現する。

3.2. Verifiable Data Repository (VDR) としての責任

Folio Remote は、メッセージの配送については「ベストエフォート（一時的なバッファ）」としての性格を持つが、権限管理にまつわる DID や VC に関しては、信頼できる Verifiable Data Repository (VDR) として機能しなければならない。

  • 公開鍵の有効性管理。
  • 必要に応じた VC の失効（Revocation）処理の執行と公開。
  • プロトコルレベルでの信頼チェーンの維持。

4. ルールベースの自動応答：データ権限の賢い委託

Folio Remote の最大の特徴は、Inbox/Outbox といった受動的なバッファの他に、「ルールベースの自動応答（Auto-responder）」 機能を備えることにある。

4.1. ローカル・コントロール、リモート・エグゼキューション

データの所有権（Data Ownership）はローカルにあるが、ローカルは「特定の条件下でこのデータを提示してもよい」という委託ルールをリモートにプッシュする。

4.2. 主な応答ユースケース

  • プレゼンスと告知: 休暇中の通知、現在のステータス表示。
  • スケジュールの可視化: 予定表の空き時間（詳細は伏せたまま枠のみを提示）。
  • 属性（Attribute）の提示: 頻繁に問い合わせがある基本的なプロフィールや、検証済みの属性（FAQ 形式）。
  • インテリジェント・ルーティング: 送信者の属性（Member か Visitor か等）に応じて、即時に保存するか、追加の検証を求めるかを判断する。

5. 結論：書類鞄（Local）と「知的郵便拠点（Remote）」の分離

当初 Folio Remote は「ローカルとリモートで同期された書類鞄」として構想されていた。しかし、真のデータ主権と自律的な応答性を追求する過程で、その役割は「マスターとしてのローカル」と「知的仲介者（Intelligent Mediator）としてのリモート」へと明確に分離された。

個人の手元にある Local Folio が**実体としての「書類鞄」**であるならば、Folio Remote は単なる受取り用の私書箱を越え、**自律的な「知的郵便拠点（Postal Hub）」や「デジタル窓口」**として機能する。

コンテキスト・aware な配送、堅牢なアイデンティティ管理（VDR）、そして委託されたルールによる知的代理応答。これらが組み合わさることで、ユーザーは自らのデータを主導権（Sovereignty）下に置きながら、常時接続社会において真に「知的で安全な」デジタルプレゼンスを確立することが可能となる。
