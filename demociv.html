Extract JPKI Attributes (WebUSB + WASM)

⚠️ Platform Compatibility: Direct WebUSB access to Smart Cards is blocked on macOS and Windows by both system drivers and browser security policies (Protected Interface Class 0x0B).
  • Android / Linux / ChromeOS: Recommended (Linux may need udev rules).
  • macOS / Windows: Even if you stop the OS smart card service (e.g. `com.apple.ifdreader`), Chrome typically blocks standard CCID interfaces. Please use "Test Simulation".
