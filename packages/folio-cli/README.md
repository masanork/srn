# Folio CLI

CLI tool for testing and demonstrating Web/A Folio capabilities.

## Usage

```bash
bun run bin/folio.ts --help
```

## Features

*   **Issue**: Simulate VC issuance (Pre-patterned Juminhyo).
*   **Present**: Connect to a physical My Number Card (via PC/SC) to generate a Verifiable Presentation.
*   **Verify**: Verify the integrity of a Web/A file (Mock implementation currently).
